# 对战模式规则

模式定义在 `server/src/game/modes.js`，新增模式只需注册一条配置。

## 1. 团队竞技 `tdm`

- 2 个队伍，击杀敌方玩家为本队 +1 分。
- 误伤（友军伤害）被本地过滤，不计分不扣血。
- 先达到 `scoreToWin` 的队伍获胜（默认 50）。
- 重生延迟 `respawnMs`（默认 3s），重生点在出生区随机。

## 2. 个人混战 `ffa`

- 无队伍，人人互相攻击。
- 击杀 +1 分，先到 `scoreToWin`（默认 30）者获胜。
- 全图随机重生。

## 3. 夺旗战 `ctf`

- 2 个队伍；地图上有 2 面旗帜（每队一面）。
- 触碰敌方旗帜（硬件上通过额外按键/触点触发 `capture` 事件）为本队 +1 分。
- 先夺 `scoreToWin`（默认 3）面旗帜获胜。
- 持旗者被击杀则旗帜原地掉落（简化版：直接重置回旗点）。

## 4. 模式配置字段

| 字段 | 说明 |
| --- | --- |
| `teams` | 队伍数；0 = 无队伍 |
| `respawnMs` | 重生延迟 |
| `scoreToWin` | 获胜分数（可被控制台覆盖） |
| `friendlyFire` | 是否允许友军伤害（默认 false） |
| `capture` | 是否有夺旗玩法 |
| `powerLevel` | 激光作用范围档位（**0..3**，W 帧下发，两通道独立映射）：0=近（室内/近战小电流）、1=标准（默认）、2=远（940nm 远档 + 850nm 升档）、3=极限（日光直射/战术设定）。映射表见 hardware-design.md §6.5 |

## 5. 规则细节

- 血量 `hp` 与伤害 `dmg` 由服务器在 `welcome`/对局开始时统一下发，改规则无需重刷固件。
- 阵亡后设备本地锁扳机并播放阵亡音效；服务器在 `respawnMs` 后下发 `control/respawn`。
- 对局结束广播 `match/end`，设备复位血量弹药并锁定扳机等待下一局。
- 战绩（击杀/死亡/胜场）在对局结束时写入 `data/stats.json`。

## 6. 激光作用范围与射程规则

近距离"贴脸必胜"由 `powerLevel` 档位缓解：近战/室内对局用 0 档（小电流、
光斑弱，850nm 同步降档），远距离对局用 2 档（大电流 + 准直透镜，850nm 同步
升档补偿日光）。硬件光学方案与校准见
[docs/hardware-design.md](docs/hardware-design.md) §6.5。规则层面可配合
约定（如"3m 内不射击"）作为公平性兜底；系统侧不做距离测量（红外无 RSSI）。
