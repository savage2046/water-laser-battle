## 2.5 头盔接收器（每玩家一套，可扩展背心接收器）

| 部件 | 型号参考 | 作用 |
| --- | --- | --- |
| 主控 | ESP32 最小系统 / ESP32-C3 | 多路红外解码、470M 上报 |
| 红外接收 ×8~10 | TSOP38238 / VS1838B（38kHz）×8 @45° + TSOP4856（56kHz）×2 | 360° 无缝全向环（940 逐站判命中 + 850 冗余），见 [omnidirectional-receiver.md](omnidirectional-receiver.md) |
| 470M 射频 | SX1262 + RadioLib（SPI 直驱），与枪端同款 | 上报"被命中"（T 帧）与位置（P 帧） |
| GPS 模块 | u-blox NEO-6M/8M 或 ATGM336H（北斗+GPS 双模） | 位置上报（战术地图/回放轨迹） |
| 蜂鸣器 | 有源蜂鸣器 | 被命中即时提示 |
| 供电 | 3.7V 锂电 / 小容量电池 | 独立供电，与枪端无物理连接 |

**工作原理**：枪 A 射击时红外帧被玩家 B 头盔上的接收器解码 → 头盔本地蜂鸣 +
上报 T 帧 → 服务器按 `master` 关系找到玩家 B 的枪 → 下发 `control/hit` →
枪端本地扣血并上报（计分权威不变）。头盔接收器覆盖 360°、无枪身遮挡，
命中判定更真实；可多件组合（头盔 + 背心）扩大受击面。
**GPS 在头盔上**：头盔处于头顶、天线朝上，卫星信号远优于枪身，位置由头盔
解析并上报（P 帧），服务器把位置归到主人设备（玩家=枪），战术地图与回放
轨迹据此绘制。

**9 轴朝向记录（回放用）**：
- MPU9250（加速+陀螺+磁力），pitch/roll 从加速度计重力分量求，
  yaw 由磁力计投影水平面求（磁北为 0，整数度）。
- **按需上电**：仅位置上报时上电读取（<20ms）随即断电——平均功耗可忽略。
- 方向随 P 帧上报（`P<devIdx>,<seq>,<latE6>,<lonE6>,<yaw>,<pitch>,<roll>`），
  服务器写入回放（kind `pos` 含朝向），后期复盘可还原玩家面朝方向。
- 磁力计需校准（硬铁/软铁）：绕 8 字旋转记录极值，固件补偿（后续版本）；
  未校准时 yaw 为相对值，pitch/roll 不受影响。

> 头盔 4 路接收 = 前/后方位 × 940nm/850nm 双波段，两波段同时收到且校验通过
> 才算命中（双通道任一成功即可，去重按 playerId+shotSeq）；MultiIrRx 通道 0/1 解码 940nm，通道 2/3 解码 850nm。

> 头盔 `config.h` 中配置 `MASTER_DEVICE_ID` 为所属枪的 `deviceId`（如 `G0001`），
> 服务器据此把命中转发给对应玩家的枪。

### GPS 功耗与省电（电源开关 + 热启动）

GPS 模块持续定位是头盔功耗大头（占 60%+），必须省电：

| 模块 | 定位电流 | 建议 |
| --- | --- | --- |
| ATGM336H（北斗+GPS） | ~25-30mA | ✅ 首选（低功耗） |
| u-blox NEO-6M | ~50mA | 可用 |
| u-blox NEO-8M/M8N | ~67mA | 精度优先场景 |

**省电原理**（`PIN_GPS_PWR` GPIO + MOSFET 高端开关控制模块 VCC）：
```
定位成功上报 → GPS VCC 断电（模块休眠，V_BCKP 保持 RTC/星历）
  → 30s 后重新上电 → 热启动 ~1s 重定位 → 上报 → 循环
平均电流: 30mA × 1s/30s ≈ 1mA（+ RTC 15µA）→ 续航提升约 10 倍
```

- **V_BCKP 必须常接 3V3**（保 RTC 星历）——否则每次都是冷启动（1~3min）
- 无 fix 兜底：上电连续搜星 30s 仍无定位 → 断电 60s 重试（室内/遮挡）
- 对局待机（未注册/无对局）时可把唤醒周期拉长（如 5min），进一步省电
- MOSFET 选 AO3401（P-MOS，低电平导通）或同类逻辑电平管

### 加速度计（运动唤醒 GPS + 室内补偿）

**结论**：加速度计用于**运动唤醒 GPS** 强烈建议（静止时 GPS 完全断电，按需定位）；
用于**室内定位补偿**需明确边界（纯加速度计无航向，完整 PDR 需 9 轴）。

| 传感器 | 待机/运动检测电流 | 说明 |
| --- | --- | --- |
| **LIS3DH** | ~11µA / 运动中断 µA 级 | ✅ 推荐（I2C + INT1 运动中断，低功耗） |
| ADXL345 | ~23µA（测量）/ ~40µA 唤醒 | 可选（SPI/I2C） |
| MPU6050（6 轴） | ~500µA 低功耗 | 有陀螺仪，可做角度，仍无航向 |
| MPU9250（9 轴） | ~1mA | 完整 PDR（含磁力计航向），室内定位升级路径 |

**运动唤醒设计**（已实现）：
```
静止: GPS VCC 断电(0mA) + 加速度计待机(µA级) + ESP32 常醒(收红外/470M)
运动: LIS3DH INT1 运动中断 → GPIO 触发 → GPS 立即上电 → 热启动定位 → 上报 → 断电
替代"周期 30s 唤醒"：静止时 GPS 完全不工作，运动按需定位
```

**室内定位补偿边界**：
- ✅ 可行：GPS 盲区桥接——无 fix 且运动时，步数×步长估算移动距离（假设方向不变），
  GPS 恢复后校正；仅短时可用（误差累计无界）
- ❌ 不可行：纯加速度计无航向，无法恢复真实行走轨迹
- 🔜 升级：换 9 轴（MPU9250），加速计计步 + 磁力计航向 + 陀螺仪姿态 → 完整 PDR

## 6. 红外帧格式（双波段冗余，38kHz/56kHz OOK）

**双波段传输相同完整数据**（射程分工 + 冗余）：
- **940nm 通道（38kHz）加准直透镜** → 远距主通道（20m+，抗阳光波段）
- **850nm 通道（56kHz）不加透镜、软件可调功率（默认低档）** → 近距通道（**≤20m**，
  20m 外默认不触发；升档按对局配置放宽）
- 两通道并行发射**相同 40bit 帧**；接收端**任一通道解码成功 + 校验通过即命中**
- 单帧 ~80ms（两通道并行，耗时等于单通道 40bit），双帧发射间隔 20ms

```
引导码(9ms载波+4.5ms间隔) 两通道同时发出
两通道相同 40bit（MSB 先发）:
  playerId(16) + weaponId(4) + team(2) + reserved(2) + shotSeq(8) + chk(8)
  bit 1 = 560µs 载波 + 1690µs 空闲
  bit 0 = 560µs 载波 +  560µs 空闲
```

| 字段 | 位宽 | 说明 |
| --- | --- | --- |
| `playerId` | 16 bit | 射手 ID |
| `weaponId` | 4 bit | 武器类型 0步枪 1手枪 2狙击 3霰弹 4机枪 |
| `team` | 2 bit | 队伍（0/1，3=无） |
| `reserved` | 2 bit | 保留（填 0） |
| `shotSeq` | 8 bit | 射击序号（**硬件真随机**，防重放作弊；精确去重） |
| `chk` | 8 bit | 校验 `chk = ~(B0^B1^B2^B3)` |

- **射程分工**：850nm 近距（≤20m，20m 外不触发，近战不误伤远距），
  940nm 远距（20m+）；接收端两路独立解码，任一成功即命中，去重按
  `(playerId, shotSeq)`（两通道收到同一帧只扣一次血）。
- **防作弊**：`shotSeq` 由 ESP32 硬件真随机数生成，不可预测。
- 双帧发射（同 shotSeq 发 2 帧）进一步提升远距离成功率，间隔 20ms。
- 38kHz 与 56kHz 载波分别由两路 GPIO 翻转产生（半周期 13.16µs / 8.93µs）。

## 6.5 激光作用范围设计（远距离 / 近距离）

### 射程分工（设计目标）

| 通道 | 射程 | 手段 |
| --- | --- | --- |
| **850nm**（56kHz） | **≤20m**（默认档位 20m 外**必须不触发**；升档后按对局配置放宽） | 软件可调功率（默认低档）+ 无透镜宽光束 |
| **940nm**（38kHz） | **20m+**（远距主力） | 准直透镜 + 功率档位可调 |

**850nm 是近距通道**：默认档位射程上限 ~20m，超出即失效——这是刻意设计，
保证近战武器不会远距生效。当前实测"20m 无法稳定触发"即为期望行为。
**软件可调功率（4 档）**：850nm 由 2 位 GPIO（IR_PWR_850_A/B）选档切换限流
电阻组，电流随 `powerLevel` 变化（见下方电路）。**默认档位（level 1）电流
必须校准在 20m 边界内**（10m 稳定触发、20m 跌破 TSOP 阈值）；升档
（level 2/3）用于日光直射补偿与战术设定（会放宽 20m 上限，由对局配置决定）。
保持无透镜宽光束，能量按 1/d² 衰减；20m+ 的命中由 940nm 透镜通道承担
（940nm 接 PIN_IR_POWER 档位切换）。

红外链路的作用范围受光学与电路共同决定，远近距离问题分开解决：

### 远距离（>15m）——能量不足、命中率骤降

| 手段 | 实现 | 增益 |
| --- | --- | --- |
| 准直透镜 | 发射 LED 前加短焦透镜（如 Φ8mm/f≈15mm），发散半角从 ~12° 压到 ~3° | 光强按 1/d² 反比，收窄光斑等效 **16 倍** 能量提升 |
| 高电流驱动 | 940nm 5mm LED，脉冲峰值电流 43/91mA（近/远档，3.3V 轨下 47/22Ω 限流；若用 5V 轨可达 100-150mA，见 §6.5 电路） | 提高峰值光功率 |
| 双帧发射 | 每次扣扳机连续发 **2 帧相同 shotSeq**（间隔 20ms） | 单帧丢失（遮挡/抖动）不影响命中 |
| 大功率档位 | `PIN_IR_POWER`（940nm）与 IR_PWR_850_A/B（850nm，4 档）GPIO 切换限流电阻 | 近距离用小电流、远距离满功率 |

### 近距离（<1m）——"贴脸必胜"与散射误触发

| 手段 | 实现 | 效果 |
| --- | --- | --- |
| 功率档位 | 近距离自动/配置降档（小电流 → 光斑弱），仍可靠解码 | 降低贴脸碾压感，且省电 |
| 遮光管/滤光片 | 接收头前加 Φ5~6mm 遮光管限制视场角（±20°）+ 对应波段带通滤光片 | 抑制侧面散射与环境红外误触发 |
| TSOP 内置 AGC | TSOP38238/TSOP4856 自动增益，近距离强光不饱和 | 接收端免调 |
| 最小射程规则 | 对局可配置（见 game-modes.md），由编码帧 + shotSeq 去重保证仅真实命中计数 | 公平性由规则层兜底 |

### 开火延时预算（双波段并行，目标 <200ms）

| 环节 | 旧方案 | 新方案 |
| --- | --- | --- |
| 单帧时长 | 48bit 串行 ~95ms | 40bit 双通道并行 ~80ms（同数据冗余） |
| 双帧间隔 | 50ms | 20ms |
| 电机联动 | 串行 delay(60ms) | **并行**（非阻塞定时器，与红外帧同时） |
| **总开火延时** | **~300ms** | **~180ms** ✓（<200ms） |

### 功率档位电路（枪端，双通道独立，软件可调）

> 引脚号为 S3 重映射编号（见 PCB/main-board-S3引脚映射.md 与 firmware/gun/src/config.h）；
> 经典 ESP32 对应 GPIO25/13/12，850nm 选档需另选 2 个空闲脚。

```
940nm 通道（远距，2 档；VCC=3.3V 稳压轨，Vf≈1.3V → 压差 2.0V）：
                    VCC(3V3)
                     │
        IR_TX(GPIO1)─R_g 220Ω─┬─ 驱动管(AO3400) 栅
                                │
                                ├── R1(近档 47Ω ≈43mA) ──┬── 940nm LED ──┐
                                └── R2(远档 22Ω ≈91mA) ──┤              │
        PIN_IR_POWER(GPIO41)─R_g 220Ω─ 模拟开关选择 R1/R2 ─┘             GND
        （各 MOSFET 栅极加 10kΩ 下拉，防上电浮空误触发）

850nm 通道（近距，4 档，软件可调；VCC=3.3V，Vf≈1.5V → 压差 1.7V；
        I_nom=40mA 设计点，档位 20.7/41.5/60.3/81mA）：
        VCC(3V3)
         │
    ┌────┼───────────── R_base(82Ω) ──┐
    │                                 │
  R_a(82Ω) ── Q_a(AO3400) ────────────┤
    │                                 │
  R_b(43Ω) ── Q_b(AO3400) ────────────┤
    │                                 │
    └──── 850nm LED(+) ── LED(-) ── Q_ook(AO3400) ── GND
    Q_ook 栅 ← IR_TX_850(GPIO2)─R_g 220Ω─ 56kHz OOK
    Q_a 栅 ← IR_PWR_850_A(GPIO44)─R_g 220Ω─   Q_b 栅 ← IR_PWR_850_B(GPIO43)─R_g 220Ω─
    （Q_ook/Q_a/Q_b 栅极均加 10kΩ 下拉；电流路径上的管全部用 AO3400，
      不能用 2N7002——其 RDS(on)@3.3V 约 7-10Ω，81mA 时压降 0.6-0.8V 吃掉 1/3 电流）
```

- 940nm：近档（`powerLevel=0/1`）小电流、远档（2/3）大电流——配合透镜打远
- **850nm：4 档电流 = 0.5 / 1.0 / 1.5 / 2.0 × I_nom**，由 GPIO 位线二进制选档
  （Q_a 导通 +0.5·I_nom，Q_b 导通 +1.0·I_nom；仅 GPIO44 可用时退化为 2 档，
  档位≥1 → 1.0·I_nom，见固件 `setPowerLevel`）
- `powerLevel` 由服务器在对局配置中统一下发（W 帧最后字段，**0..3**），两通道独立映射：

| `powerLevel` | 940nm | 850nm |
| --- | --- | --- |
| 0 | 近档 | 0.5·I_nom（室内/近战，射程更短） |
| 1（默认） | 近档 | 1.0·I_nom（**= 原 R3 校准电流，20m 边界**） |
| 2 | 远档 | 1.5·I_nom（日光直射补偿，放宽 20m） |
| 3 | 远档 | 2.0·I_nom（极限/战术设定） |

- 850nm 各档电流校准：**默认档（level 1）先按原 R3 实测电流定 I_nom**，再按
  比例配 R_base / R_a / R_b（R_base=R_a=1.7V/(0.5·I_nom)、R_b=1.7V/(1.5·I_nom)，
  1.7V = VCC(3V3) − Vf(850nm≈1.5V)）。**设计点 I_nom=40mA → R_base=R_a=82Ω、
  R_b=43Ω（E24，0805），档位实测 20.7/41.5/60.3/81mA**；I_nom=45mA → 75/75/39Ω。
  电流路径上的 MOSFET 一律 AO3400（RDS(on)@3.3V≈45mΩ，可忽略）；栅极串 220Ω、
  加 10kΩ 下拉。以校准靶实测为准：10m 应稳定触发，档 0/1 在 20m 不触发。

### 双波段作用距离参考（工程估算）

**分工**：850nm 默认档位低功率无透镜（**射程 ≤20m**，20m 外不触发；升档按对局
配置放宽），940nm 透镜 + 档位可调（20m+ 远距主力）。发射 5mm LED、接收
TSOP38238/4856：

| 条件 | 850nm（软件可调，默认档 0/1 近距） | 940nm（透镜 + 档位，远距） |
| --- | --- | --- |
| 10m 内 | ✅ 稳定触发（设计射程） | ✅ |
| **20m** | ⚠️ **临界：档 0/1 接近/低于阈值（设计上限）**；档 2/3 可放宽 | ✅ |
| 20m+ | ❌ 默认不触发（刻意限制）；升档后按对局配置 | ✅ 40-80m（远档） |
| 日光直射 | 3-8m（AGC 压缩，射程更短）→ **升档 2/3 补偿** | 20-40m（抗阳光波段） |

- **850nm 默认限距是设计意图**：近战通道在 20m 外必须失效，避免远距误触发；
  升档属于显式战术/日光配置，由对局 `powerLevel` 控制
- 940nm 承担全部 20m+ 命中（抗阳光波段 + 透镜 + 档位可调）
- 实际以校准靶实测为准（10m 应触发、20m 档 0/1 应不触发，遮阳 vs 直射两组；
  升档后重测各档边界并写入上表）。

### 校准建议

1. 固定两把枪相距 1m/5m/15m/30m，调整透镜焦距与限流电阻，使各距离解码成功率 >95%。
2. 日光直射会压制 TSOP 灵敏度（AGC 压缩），**带通滤光片必装**；阴天/室内作用距离最远。
3. 多接收头（头盔 2~4 路 + 枪身 1 路）取并集，配合遮光管消除方向盲区。
4. **单人校准**：使用激光校准靶（9 路阵列）检测光斑位置/宽度与编码正确性，
   见 [calibration-target.md](calibration-target.md)。
5. 各档位光功率指标（峰值 mW / mW/sr）与换算方法见
   [link-budget.md](link-budget.md)——先按指标定电流量级，再用校准靶微调。

## 7. 470MHz LoRa 帧格式

紧凑 ASCII，一帧一个 LoRa 包（≤ 64 字节），事件帧带 16 位自增 `seq`，

## 8. 安装与合规建议

1. 发射 LED 与接收头分置枪身两侧，避免同枪自触发；接收头前加 940nm 滤光片抗阳光。
2. 接收头视野有限，建议每枪 2~4 路接收头并联取并集。
3. 天线竖直放置、远离金属件；SX1262 远离电机等强干扰源。
4. **GPS 天线朝上放置**，远离 470M 天线与电机（电磁干扰会掉星）；冷启动
   首次定位需开阔天空 1~3 分钟，热启动 <10s。室内/隧道无定位时不上报位置。
5. 网关天线尽量架高（3~5m），扩大单网关覆盖与重叠漫游区。
6. **频段合规**：470.0MHz 处于国内合法开放的 470~510MHz 微功率短距离频段，
   无需许可（发射功率 ≤ 22dBm，符合微功率设备限值）。全队频率/参数必须一致。
7. 电池防反接、线束热缩管固定。
