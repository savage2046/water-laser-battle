# 激光校准靶（光路检测与校准）——设计定稿 v3（5×3 二维阵列 / ESP32-S3）

> 状态：**设计定稿 v3（2026-09-04）**，固件 `firmware/target` v2.0.0（env:esp32s3）。
> 形态：**15× XL-IRM-V838M3/TR 组成 5 列×3 行二维阵列（100×40mm）**，每格一颗
> **WS2812B(5V) 命中灯**，光斑照到哪格哪格亮 → **直接读光斑 2D 位置/形状**；
> 中心格兼 38k 帧解码（身份/强度验证）。
> 用途：单人校准 **940nm 光路**（不需要解码完整帧即可用；中心格解码用于对中确认）。

## 1. 用途与判读

| 检查项 | 判读方式 | 合格判据 |
| --- | --- | --- |
| 光斑 2D 位置 | 灯阵亮格 + OLED `x%/y%` | 亮区质心 ≈ 中心格：`x≈0 y≈0` |
| 光斑宽度/高度 | 亮格 `span 宽×高` | 按 §5 距离表（±1 格） |
| 光斑形状 | 亮格分布（方/圆/散） | 集中无散点 |
| 对中（光轴） | 中心格白闪（解码成功） | 每发都白闪 = 光束正中中心格 |
| 编码/强度 | OLED P/W/T/S、STRONG/WEAK | 与枪端一致；20m 远档 ≥STRONG |

## 2. 布局

```
靶面 100mm(宽) × 40mm(高)，格距 20mm（5 列 × 3 行，行主序 idx=row*5+col）
row0 ●──●──●──●──●     y=+20mm
row1 ●──●──●──●──●     y=0   （中心格 idx7 = row1,col2 兼解码）
row2 ●──●──●──●──●     y=−20mm
     x=−40 −20  0 +20 +40mm
每格 = 1× XL-IRM（顶视窗朝枪）+ 正下方 1× WS2812B
靶面外沿标 cm 刻度（x:0~10cm 中心 5cm；y:0~4cm 中心 2cm）
```

- 靶面覆盖 **100×40mm**；>5m 后光束高度可能超出 3 行（见 §5 限制说明）
- 中心格 = 5 列 3 行几何中心，兼 38k 帧解码（FrameRx 通道 0）

## 3. 硬件

| 部件 | 数量 | 说明 |
| --- | --- | --- |
| 38kHz IRM：XL-IRM-V838M3/TR | 15 | 成兴光 LCSC **C51900936**；38k(37.9k)/940nm/±45°/0.22~0.6mA；TTL 低有效 |
| WS2812B（5V 版）命中灯 | 15 | 每格一颗，行主序串接；数据需 3.3→5V 电平转换 |
| 74HCT1G125 | 1 | 电平转换（SOT-23-5：1=OE接地 2=A 3=GND 4=Y 5=VCC），勿用 AO3400A 转数据 |
| ESP32-S3 | 1 | LCKFB-ESP32S3R8N8 或任意 S3 板（GPIO 号通用，见 §4） |
| SSD1306 OLED 0.96" | 1 | 软件 I2C（21/38） |
| 有源蜂鸣器 | 1 | GPIO39 命中提示 |
| 56kHz IRM（预留不贴） | 1 | 焊盘预留 GPIO40（56k 暂缓） |

**接线（LED 段）**
```
+5V ──100µF电解+0.1µF── GND        （灯带/HCT 电源端储能；15 颗全亮≈300mA@5V）
ESP32 GPIO17(3.3V) ──100Ω── 74HCT1G125 A；Y ──100Ω── WS2812B #1 DIN → #2…#15
74HCT1G125 VCC=5V、GND 与 ESP32 共地
IRM 输出：每格独立 GPIO（INPUT_PULLUP）；IRM VCC=3.3V（就近 0.1µF）
```

## 5. 光路判据（940nm 远距通道，f≈100 透镜、d≈1mm 待实测）

光斑边长 ≈ `z·d/f`（方形芯片成像），与格距 20mm 换算**期望覆盖格数**：

| 距离 z | 光斑边长 | 期望 span（宽×高） | 备注 |
| --- | --- | --- | --- |
| 1m | ≈1cm | **1×1** | 中心单格 |
| 3m | ≈3cm | **2×2** | |
| 5m | ≈5cm | **3×3** | 纵向接近满 3 行 |
| 10m | ≈10cm | **5×3（纵向溢出）** | 横向 5 格满；纵向 3 行只截到中间 4cm，只作 y 截线参考 |

- 实测 d≠1.0mm 时按速查卡整体缩放（d 由试镜反推：f≈5.1×D₀@10m）
- **亮格分布判读**：质心 `x%/y%` = 亮区相对中心格偏移（±100≈±1 格）；
  亮区偏 → 透镜反向平移（光斑偏左 → 透镜右移）；亮区过大/带散点 → 检查对焦与散射
- 近距离（1~5m）完整读 2D 形状；10m+ 主要看横向 5 格是否铺满 + 中心格解码是否稳定

## 6. 显示与固件行为（firmware/target v2.0.0）

OLED（6 行）与 15 颗灯同步（60ms 刷新）：
```
P3 W2 T0 S12      行1 解码（中心格）
STRONG span3x3    行2 强度 + 宽×高格数
XXXXX             行3 row0（行主序）
.XXXX             行4 row1
..XXX             行5 row2
x+0% y+0%         行6 2D 质心偏移（0=对中）
```
- **灯阵**：命中格亮绿（15 颗行主序）；中心格解码成功白闪 300ms；空闲弱绿微亮（`LED_IDLE_DIM`）
- 中心格"收到"由 FrameRx 活动标志置位（无完整帧也亮，与其它格一致）
- 命中窗口 800ms 后清空；双帧判 STRONG（shotSeq 去重）

**校准流程**：摆靶 → 1m 对中（中心格白闪）→ 调透镜平移/焦距 → 3/5/10m 各打 ≥5 发，
记录 span/质心与 STRONG 占比（20 发成功率 >95% 合格）。

## 7. 扩展与限制

- **纵向覆盖**：3 行只测 40mm 高；如需 10m 全高光斑 → 扩成 5×5=25 格
  （`ARRAY_COLS/ROWS` 宏可改，但 main.cpp 的 ISR 表需同步扩到 25 路）
- 垂直分辨率不够时可用"中心密边缘疏"格距（后续版）
- 56k 近距通道恢复：补 1 颗 56k 件到 GPIO40（FrameRx 通道1 代码就绪）
- 旋转扫掠测 2D 剖面的实验版：见对话结论（静态面阵已覆盖 1~5m 主用途）
