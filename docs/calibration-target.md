# 激光校准靶（光路检测与校准）

## 1. 用途

校准靶是**单人校准设备**：把枪对准靶子射击，靶子即时反馈光路状态，用于：

1. **光斑位置检测**：准直透镜是否居中、光轴是否对准（偏左/偏右/偏高/偏低）
2. **光斑宽度估计**：发散角是否合格（光斑覆盖几颗接收头 → 估算光斑直径）
3. **编码正确性验证**：解出 48bit 双波段帧，检查 playerId/weapon/team/shotSeq
4. **双波段同步验证**：940nm 与 850nm 两通道是否都正常
5. **信号强度粗判**：双帧发射收到 2 帧=强，1 帧=弱，0 帧=未命中

## 2. 硬件设计

```
┌────────────────────────────────────────────────┐
│ 靶面 (16cm × 4cm)                               │
│ ┌─┬─┬─┬─┬─┬─┬─┬─┬─┐                           │
│ │T│T│T│T│T│T│T│T│T│ 9× TSOP38238 (940nm/38kHz) │
│ └─┴─┴─┴─┴─┴─┴─┴─┴─┘  间距 2cm，中心颗兼做帧解码 │
│           ▲ 中心颗                               │
│   TSOP4856 (850nm/56kHz)  ×1 双波段验证          │
├────────────────────────────────────────────────┤
│ SSD1306 OLED 128x64：靶面阵列图/解码结果/强度    │
│ 蜂鸣器：命中提示                                  │
└────────────────────────────────────────────────┘
```

| 部件 | 数量 | 作用 |
| --- | --- | --- |
| TSOP38238（38kHz） | 9 | 横向阵列测光斑位置/宽度；中心颗兼做 940nm 帧解码 |
| TSOP4856（56kHz） | 1 | 850nm 通道解码（双波段冗余验证） |
| SSD1306 OLED | 1 | 可视化显示 |
| 有源蜂鸣器 | 1 | 命中提示 |
| ESP32 | 1 | 主控 |
| 遮光隔板 | 9 | 每颗接收头之间竖隔板（±20° 视场角隔离，防邻颗串扰） |
| 标尺刻度 | — | 靶面上下标注 cm 刻度，方便记录光斑位置 |

## 3. 接线（`firmware/target/src/config.h`）

| 信号 | ESP32 引脚 | 说明 |
| --- | --- | --- |
| ARRAY_RX0..8 | GPIO 26/25/36/39/34/35/14/13/12 | 9 颗阵列 TSOP 输出（下降沿中断，仅输入） |
| RX850 | GPIO 27 | TSOP4856 输出（中断，帧解码） |
| OLED_SDA / SCL | GPIO 21 / 22 | SSD1306 I2C |
| BUZZER | GPIO 33 | 命中提示 |

> 阵列引脚多为纯输入（34/35/36/39），TSOP 输出为推挽（空闲高电平），
> 无需上拉；每颗都挂 `attachInterrupt(FALLING)` 置标志即可。

## 4. 使用与读数

1. 靶子摆正，枪距 1m 射击（无透镜校准）或 5~15m（准直透镜校准）。
2. 看 OLED：
   - `[x x X X X x x x x]`：`X` = 收到载波的颗 → 光斑位置与宽度
   - `P3 W2 S12`：playerId=3、weapon=2、shotSeq=12（编码验证）
   - `SPAN 3`：光斑覆盖 3 颗（≈4cm）→ 发散角评估
   - `STRONG/WEAK`：双帧收到情况
3. 调透镜：光斑偏左 → 透镜右移；光斑太宽 → 增大焦距/收窄发散角。
4. 光斑居中且覆盖 ≤3 颗（≈4cm @1m）、双波段均解出 → 校准合格。

## 5. 扩展

- 垂直阵列（5 颗纵向）可测光斑高度与垂直居中（两轴校准）。
- 加光电二极管 + ADC 可测真实光强等级（TSOP 只有数字输出，当前强度为粗判）。
- 加 SD 卡/串口可记录多次射击数据（散点分布 → 光轴稳定性）。
