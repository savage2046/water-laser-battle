# 户外强光干扰可靠性设计

## 1. 问题分析

太阳光在 850~1100nm 红外波段有大量能量，对红外激光链路造成三类干扰：

| 干扰 | 机理 | 表现 |
| --- | --- | --- |
| AGC 压缩 | TSOP 内置 AGC 按环境红外总量自动降增益 | 远处激光（弱信号）被压掉，作用距离骤降 |
| 误触发 | 阳光直射/闪烁（云、树、人遮挡）产生类载波脉冲 | 假帧、无端扣血 |
| 解码失败 | 强背景光压低信号幅度，脉宽失真 | 校验失败、漏命中 |

**重要有利因素**：940nm 恰处于太阳光谱的水汽吸收低谷，940nm 波段本身
就是红外遥控抗阳光的标准选择——**本系统双通道波长已统一 940nm，近/远通道
共享这一抗阳光优势**（这也是当初弃用 850nm 近距通道的原因之一）。

## 2. 四层解决方案（优先级从高到低）

### 第一层：光学滤光（最有效，必做）

| 手段 | 实现 | 说明 |
| --- | --- | --- |
| 窄带带通滤光片 | 接收头前加 **940nm ±10nm** 干涉滤光片（双通道统一，一种料号全装） | 阻断 90%+ 环境红外，AGC 不再被压缩 |
| 遮光罩/遮光管 | 接收头前加 Φ5~6mm 遮光管，视场角限制 **±10°** | 大角度阳光无法进入；配合准直光束（±3°）恰好匹配 |
| 光阱结构 | 接收头周围深色吸光/内螺纹消光 | 消除内部散射 |

> 波长统一 940nm 后，近/远通道同处太阳光谱水汽吸收低谷、抗阳光一致；近距
> 通道（56kHz）功率低、受 AGC 压缩的相对影响更大，**滤光片必装**。双通道传
> 相同完整帧，任一通道成功即命中。

### 第二层：电路与环境光自适应

- 接收头旁放**光敏二极管 + 分压电阻 → ADC**（如 S3 GPIO10/ADC1_CH10）。
- 固件周期采样环境光，分级（LOW/MID/HIGH/EXTREME）：
  - HIGH/EXTREME：自动把 `powerLevel` 提到 2（远距远档 + 近距升档），补偿 AGC 压缩；
  - OLED 状态行提示 `LIGHT:HI`。
- 可选：环境光等级随心跳上报服务器（预留，暂未实现）。

### 第三层：固件抗假帧与防作弊

已有校验（全部保留）：
- 引导码 9ms + 4.5ms 间隔（强过滤器，阳光很难精确复现）
- 每 bit 脉宽容差（±300µs）
- 双通道各传完整 40bit 帧（任一成功即命中）+ 校验
- `(playerId, shotSeq)` 精确去重

**随机射击序号防作弊**：
- 射击序号 `shotSeq` 由 **ESP32 硬件真随机数**（`esp_random()`）生成，每发不可预测。
- 固定递增序号每 256 发循环，作弊者可记录并预测序号后重放射击帧（旧帧不在
  去重表内即被当作新命中）；随机序号消除可预测性，重放伪造难度大幅提升。
- 双帧发射的两帧共用同一随机序号：接收端按 `(playerId, shotSeq)` 精确去重，
  同一射击帧无论几路接收头收到只扣一次血，双帧不重复计。

### 第四层：系统与使用

- 户外对局：服务器 `powerLevel` 强制 2（远距远档 + 近距升档）；极端强光可用 3。
- 校准靶：户外校准注意日光影响读数（用靶子做光斑检测时遮挡阳光直射）。
- 阴天/室内：作用距离最远（AGC 不压缩），是最佳测试环境。

## 3. 可靠性测试方法

1. **日光对比**：同一距离、同一功率，晴天直射 vs 遮阳下解码成功率。
2. **闪烁干扰**：手持反光板在枪与靶之间快速晃动，观察假命中计数。
3. **距离衰减曲线**：1/5/15/30m 各打 20 发，统计成功率（校准靶自动统计）。
4. **档位对比**：powerLevel 0/1/2/3 在强光下各测 20 发，确认自动升档有效（近距通道各档边界同步记录）。

## 4. 配置汇总

| 配置 | 位置 | 户外建议 |
| --- | --- | --- |
| 940nm 带通滤光片 | 硬件 | 必装 |
| 遮光罩 ±10° | 硬件 | 必装 |
| `PIN_LIGHT_SENSE` ADC | gun/config.h | 接光敏二极管 |
| 自动升档 | gun/main.cpp | 开启（默认） |
| 随机 shotSeq 防作弊 | gun/main.cpp | 硬件真随机，始终开启 |
| `powerLevel` | server modes.js | 户外 2 |
