# wire-probe —— 4 个管脚输出固定频率方波

只有一个功能：**开机后 4 个管脚持续输出 10 / 100 / 500 / 1000 Hz 方波**。
不用 SPI、不用任何库。

| 管脚 | 枪端主板 / 网关板（ESP32-S3） | 频率 | 占空比 |
| --- | --- | --- | --- | --- |
| NSS | G16 | **10 Hz** | 50% |
| SCK | G42 | **100 Hz** | 50% |
| MOSI | G15 | **500 Hz** | 50% |
| RST | G46 | **1000 Hz** | 50% |

> 2026-09-12 起网关板改用与枪端**相同的接线**（见 `firmware/gateway/src/config.h`）。

## 烧录

```bash
cd firmware/wire-probe
pio run -e gun-s3 -t upload     # 枪端 / 网关板都用这个 env（2026-09-12 起接线相同）
```

## 示波器

- 探头地接**板 GND**，探头点对应管脚（或对应的模组焊盘）。
- 触发任一通道上升沿即可；四路来自同一个 4kHz 定时器，**相位对齐、频率精确**。
- 幅度应为干净的 0V ↔ 3.3V。

| 通道 | 频率 | 建议时基 |
| --- | --- | --- |
| NSS | 10 Hz | 20 ms/格 |
| SCK | 100 Hz | 2 ms/格 |
| MOSI | 500 Hz | 500 µs/格 |
| RST | 1000 Hz | 200 µs/格 |

## 说明

- 时基 250µs（4kHz 硬件定时器），10/100/500/1000 Hz 都是它的整数分频
  （周期 400 / 40 / 8 / 4 个 tick），所以频率不会漂，也不受串口、主循环影响。
- `loop()` 是空的，波形全部由定时器中断产生。
- 串口只在开机打印 4 行（板名 + 每根管脚的频率），之后不再输出。
- 模组驱动的那三根线（MISO / BUSY / DIO1）本固件**完全不碰**。
- 模组 3.3V 供电；`RST` 在翻转意味着模组全程处于复位状态 —— 本固件只看波形，不涉及射频。

## G46（模组 RESET）这一路的硬件事实

来自 `DS_SX1262.pdf`（Semtech V1.1_2017.12 中译版）与 `Ra-01S_V1.1.2规格书`：

| 项 | 手册原文 / 出处 |
| --- | --- |
| 引脚 | 15 脚 `NRESET`，类型 **I/O**，"复位信号，低有效"（第 12 页 表 2-1） |
| 内部上下拉 | 第 53 页 **表 8-3「每种芯片模式的数字端口配置」：NRESET 在所有模式下都是 `IN PU`** → **输入 + 内部上拉**；表下注释："PU = 典型条件下用一个 50KΩ 上拉；PD = 典型条件下用一个 50KΩ 下拉"。**手册里没有任何内部下拉。** |
| 复位时序 | 第 49 页 §8.1：需**至少 50µs 低电平**（一般 100µs） |
| 电平阈值 | 第 21 页 表 3-10：`VIL_N`（NRESET 输入低电平）= −0.3 ~ **0.2×VBAT**（3.3V 时约 0.66V）；脚注 1：**NRESET 与 DIO3 参考 VBAT**，其余数字 IO 参考 VBAT_IO。**只规定了低电平阈值，没有规定高电平阈值。** |
| 模组侧 | Ra-01S 第 4 脚 = `RESET`；规格书注意事项(2)："特殊 IO 口的上下拉，需参考规格书的使用说明，此处会影响到模组的启动配置" |

**结论**：模组 RESET 脚**自身是"上拉"**（悬空 = 高 = 不复位），不会把线拉低。50kΩ 上拉对 ESP32 推挽驱动（几十 Ω）的影响只有 0.1% 量级，**不可能把 1kHz 方波变成"频率不对"**。

能让频率读数出错的，只有两种外部情况 —— 用 `RST_SLOW_TEST`（见 `src/main.cpp` 第 18 行）区分：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 2Hz 干净、1kHz 才乱 | 这一路有**容性负载/串阻**（RC 把方波积分成三角波），例如复位脚对地并了电容 | 别用 1kHz 驱动复位脚（正式固件里它是静态电平） |
| 2Hz **还是乱/没信号** | 这一路**断线、虚焊、接触不良**（串阻与 50kΩ 内部上拉形成分压，节点变高阻后被邻近线串扰） | 查线/焊点，与频率无关 |

> 另一个有用的排除法：RESET 内部上拉 → **把 G46 这根线直接拔掉，模组照样能工作**（很多模组 RESET 悬空即可）。所以"拔掉反而正常"不矛盾。
> 另外表 8-3 显示 Reset / Start-up / Sleep 期间 **BUSY = `HIZ PU`（上拉）**，只有进入 STBY_RC 之后的 active 模式才是 `OUT` —— 上电未配置时看到 BUSY 为高电平属正常，别误判成线坏。
