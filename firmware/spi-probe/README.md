# spi-probe —— SPI 接口测试（面向示波器的一版，已被 `spi-read` 取代）

> **只测 SPI 接口**：引脚 → 波形 → 芯片应答。上电什么都不发，按键才发，
> 一次只发一个干净、可触发的帧（NSS 下降沿触发），串口输出**全是 ASCII**。
>
> ⚠️ 这是最早的「示波器版」，功能已被 **`firmware/spi-read/`（第二步：读寄存器）** 取代 ——
> 后者既能看波形（`4`/`5` 单帧）又能直接给出"SPI 通不通"的硬判据（版本串/同步字/复位值）。
> 本工程保留作为对照：它的 `b` 键（位翻转，不经 SPI 外设）在怀疑 SPI 外设本身时仍有价值。

## 接线（枪端 / 网关通用）

| 信号 | GPIO | 说明 |
| --- | --- | --- |
| NSS | G16 | SPI 片选（低有效，空闲高） |
| SCK | G42 | SPI 时钟 |
| MOSI | G15 | SPI 主机输出 |
| MISO | G41 | **模组 → ESP32**，只做输入 |
| RST | G46 | 复位（低有效） |
| BUSY | G45 | 忙指示（只做输入） |

## 上电后什么样

上电只停在**空闲态**：`NSS=高、SCK=低、MOSI=低、RST=高`，**什么都不发**
（示波器上应该是一条干净平线）：

```
===== spi-probe v2 : SPI interface test (minimal) =====
board : gun-board / gateway（ESP32-S3，接线相同）
pins  : NSS=G16 SCK=G42 MOSI=G15 MISO=G41 RST=G46 BUSY=G45
idle  : NSS=H SCK=L MOSI=L RST=H  -> nothing is sent until you press a key
scope : trigger on NSS falling edge; one frame = 8/16/19 clocks, then a gap
        clk=250kHz (1 clock = 4us)  gap=100ms
```

⚠️ **如果上电后示波器上就有信号**，那不是本固件发的 —— 先查模组自激 / 别的东西在驱动这根线。

## 示波器怎么设

- 探头地接**板 GND**；CH1=NSS CH2=SCK CH3=MOSI CH4=RST，点模组焊盘或 ESP32 引脚。
- 触发：**NSS 下降沿**，用 **SINGLE** 抓单帧。
- 时基对照：

| 时钟 | 1 时钟 | 8 时钟帧（`1`） | 16 时钟帧（`4`） | 152 时钟帧（`5`） |
| --- | --- | --- | --- | --- |
| **250kHz（默认）** | 4µs | 32µs | 64µs | 608µs |
| 1MHz | 1µs | 8µs | 16µs | 152µs |
| 8MHz | 125ns | 1µs | 2µs | 19µs |

## 命令（单键，不用回车）

| 键 | 动作 | 线上字节 | 看什么 |
| --- | --- | --- | --- |
| `0` | 停发回空闲（**上电默认**） | 无 | 干净基线 |
| `1` | 连续发 1 字节 `0xAA` | 8 时钟 | 纯波形 |
| `2` | 连续发 `C0 00`（GetStatus） | 16 时钟 | 芯片回 1 字节 |
| `3` | 连续发 `1D 03 20`+16×`00`（读版本串） | 19 字节 / 152 时钟 | MISO 应是 ASCII `SX1268` |
| `4` / `5` | **单次**发一帧 GetStatus / 版本读 | 16 时钟 / 19 字节 | 配 SINGLE 触发看第一帧 |
| `b` | 位翻转 1 字节 `0xAA` @1kHz（**不经 SPI 外设**） | 8 时钟×500µs | 与硬件 SPI 对照 |
| `s` | 时钟 250k → 1M → 2M → 8M → 16M | — | 逐档提速找拐点 |
| `g` | 帧间隔 20 → 100 → 500 → 2000ms | — | 触发不好抓就加大 |
| `i` | 打印 7 根线电平 + 状态 | — | 核对空闲电平 |
| `l` | 逐帧日志 开/关（默认关） | — | 需要每帧 hex 才开 |
| `r` | 复位脉冲（RST 低 2ms） | — | 可选 |
| `h` | 帮助 | — | — |

## 波形 → 结论

| 示波器上看到 | 结论 |
| --- | --- |
| NSS 没有下降沿 | NSS 线断/虚焊/接错脚 |
| NSS 有低脉冲但 SCK 一个时钟都没有 | SCK 断/接错 |
| SCK 正常但 MOSI 一动不动 | MOSI 断/接错 |
| 16/152 个时钟内 MISO 一直不变 | MISO 断（恒高）/ 短路（恒低）/ 没选中 |
| MISO 有数据 | ✅ SPI 四线通 |
| 幅度不足 3.3V / 边沿圆钝 | 线长 / 容性 / 串阻 / 接触不良 |
| 低速全对、高档开始出错 | 接触/共地问题 → 降到能全对的最高档 |

## 烧录

```bash
cd firmware/spi-probe
pio run -e gun-s3 -t upload      # 枪端 / 网关板都用这个 env
pio device monitor -b 115200
```

## 文件
