# rf-check —— LoRa 模组体检固件（SX1268 / Ra-01S）

**目的：区分「模组没焊接好」与「模组本身坏了」。**

裸 SPI 实现（**不依赖 RadioLib**），把变量降到最少；上电自动跑 9 项检查，之后可用单键复测。
串口输出全 ASCII（避免编码问题），本文件是判读表。

## 烧录与使用

```bash
cd firmware/rf-check
pio run -e gun-s3 -t upload        # 枪端板 / 网关板接线相同，同一个 env
pio device monitor -b 115200
```

打开监视器后**按一下复位**（USB-CDC 会吞掉开机那段），即可看到 [1]~[7]。
之后单键：

| 键 | 作用 |
| --- | --- |
| `s` | 全部重跑 |
| `t` | 连发 10 帧（配对端的 `lora-rx`，判"到底辐射出去没有"） |
| `r` | 连收 10 秒（配对端的 `lora-tx`，判"收得到吗"） |
| `w` | 只跑寄存器写回环 |
| `e` | 清芯片错误标志 |
| `f<MHz>` | 换频点（如 `f470.5`），对端也要改 |
| `i` | 打印当前状态（freq/busy/rst/dio1/err/irq） |

## 判读表

| 项 | 看什么 | 正常 | 异常的含义 |
| --- | --- | --- | --- |
| [1] RST/BUSY | 释放复位后 BUSY 应回低 | PASS | BUSY 恒高 → **BUSY 线没接好**／模组没上电／模组坏 |
| [2] 版本串 `0x0320` | `"SX1268 V2F 2F02…"` | PASS | 读不到或乱码 → **SPI 四线或 RST 没焊好**（最先查这条） |
| [3] 寄存器写回环 | 写 `34 44` 能读回 `34 44` | PASS | 读不回 → **MOSI 或 MISO 其中一根没通**（只读版本串可能"看起来正常"） |
| [4] 状态字节 ×8 | 稳定且 `chipMode=2`（STBY_RC） | PASS | 抖动/模式异常 → SCK 或 NSS 接触不良 |
| [5] `GetDeviceErrors` | `0x0000` | PASS | `XOSC_START`→晶振没起振；`PLL_LOCK`→锁相环；`PA_RAMP`→功放；`*_CALIB`→校准失败 ⇒ **模组自身损坏**（或晶振/供电有问题） |
| [6] RSSI 噪声底 | 有起伏（min≠max） | PASS | 读数一动不动 → **接收链路/天线**没通（或模组 RX 坏） |
| [7] 发一帧 | `TX_DONE` + 空口 ≈9.3ms + `dio1=1` | TX_DONE | 无 `TX_DONE` → 芯片没发出去（SPI/配置）；`dio1=0` → DIO1 线没接（不影响功能）；`err` 非 0 → 射频部分 |
| [8] 连发 10 帧 | 对端 `lora-rx` 收到 | 收到 | **芯片侧全 PASS 但对端 0 包 = 发射链路/天线/PA** ← 就是"芯片测得到、辐射不出去" |
| [9] 连收 10 秒 | 对端 `lora-tx` 的包 + RSSI/SNR | 收到 | 0 包 → 接收链路/天线；收到了但 RSSI 极低（< −100dBm）→ 天线/前端有问题 |

## 结论矩阵（最常见三档）

| 现象组合 | 结论 | 处理 |
| --- | --- | --- |
| [2] 或 [3] 直接 FAIL | **焊接问题**：SPI 六线里至少一根没通 | 补焊（先看 NSS/MISO/MOSI/SCK/RST/BUSY 六个焊点）后重测 |
| [2]~[4] PASS，但 [5] 报 XOSC/PLL/PA/校准 | **模组（或其晶振）损坏** | 换模组 |
| [2]~[5] 全 PASS，[8] 对端 0 包 / [9] 0 包 | **射频链路问题**：天线（SMA/IPEX/焊点）→ 再查模组 PA | 先查天线，再换模组复测 |

## 与对端配合（关键：[8]/[9] 才是"辐射"的判据）

`TX_DONE` 只说明**芯片把帧发出去了**，不代表**辐射到空中**（Ra-01S 的 RF 开关由 DIO2 驱动，
若该命令漏发或 PA/天线有问题，芯片照样报 TX_DONE）。所以判"辐射"必须用对端：

- **判本板发射**：另一块板烧 `lora-rx`（同频点）→ 本板按 `t`
- **判本板接收**：另一块板烧 `lora-tx` → 本板按 `r`
- **两块互换角色各跑一遍**，即可定位是"这块板只发不出去"还是"只收不到"

## 与其他测试固件的关系

- `firmware/spi-read/`：只读寄存器（本固件是它的超集，多了写回环/错误标志/收发）
- `firmware/lora-tx/`、`firmware/lora-rx/`：收发对端（本固件的 [8]/[9] 直接配它们用）
- `firmware/wire-probe/`：更底层的"四根脚输出方波"（示波器查焊盘通断，连 SPI 都不用）
